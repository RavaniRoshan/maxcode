## Result

Two README problems were found and fixed:

- the Demo block never exported MAXCODE_REASONING_EFFORT=none, so Ollama
  answered "qwen2.5:3b does not support thinking" and the run stopped with
  `stopped: error`;
- the Benchmark block did not copy a maxcode.toml, so maxcode bench exited 2
  with "No maxcode.toml file found" on a clean clone.

The fork build lines and the global npm install were not executed; see the
notes above for what was checked instead.
