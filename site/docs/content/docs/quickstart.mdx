## 1. Install the CLI

Requires Python 3.12+, [uv](https://docs.astral.sh/uv/), and git.

```bash
uvx --from git+https://github.com/RavaniRoshan/maxcode maxcode --help
```

Or work from a checkout:

```bash
git clone https://github.com/RavaniRoshan/maxcode.git
cd maxcode
uv sync
uv run maxcode --help
```

## 2. Install an engine

The engine is the process that edits files and runs commands. Stock Codex
0.165 or newer is the one-minute path:

```bash
npm install -g @openai/codex@0.165.0
codex --version
```

The adapter also accepts `maxcode-engine` on `PATH`, or an explicit
`MAXCODE_ENGINE_BIN`. See [Providers](/docs/providers) for the full selection
order.

## 3. Configure a local provider

The live demo used a hosted planner and a local Ollama worker. Pull the worker
model and create `maxcode.toml`:

```bash
ollama pull qwen2.5:3b
export POLLINATIONS_KEY=anonymous   # non-empty placeholder for the anonymous tier
export OLLAMA_API_KEY=local         # Ollama ignores the value
```

```toml title="maxcode.toml"
[provider.pollinations]
base_url    = "https://text.pollinations.ai/openai"
api_key_env = "POLLINATIONS_KEY"

[provider.local]
base_url    = "http://127.0.0.1:11434/v1"
api_key_env = "OLLAMA_API_KEY"

[planner]
provider = "pollinations"
model    = "openai"          # the service's alias for gpt-oss-20b

[worker]
provider = "local"
model    = "qwen2.5:3b"

[checks]
test = "python3 -m pytest -q"
```

The planner must follow the JSON plan schema. Local 3B planners failed that
schema or proposed editing tests on 2026-11-01; the probes are in
`docs/BENCH.md`. The anonymous Pollinations tier is rate-limited and returned
HTTP 400 on a larger repository. Use a funded planner if you need reliable plans
at scale.

## 4. Run a task

In a git repository with a failing test:

```bash
maxcode run --yes --config maxcode.toml "Edit app.py so add(a, b) returns a + b. Run python3 -m pytest -q. Do not change tests."
```

The run prints a summary like:

```text
steps: 1/1  cost: $0.0000  tokens: 7393 in / 1293 out
cost is partial: some calls lacked a price or a token count
```

Exit code `0` means the verifier passed. A non-zero code means the work is not
done. See [Commands](/docs/commands) for every exit code.
