maxcode

A terminal coding agent that marks a task done only after checks pass.

The problem

Coding tools often report a task as done when it is not done. The user finds the failure by hand.

The verifier loop

A planner splits the task into steps. A worker edits files for one step. A verifier runs tests, builds, and lint commands. A step is done only when every check passes. Every step starts from a git checkpoint.

Install in 60 seconds

git clone https://github.com/roshanravani/maxcode.git
cd maxcode
uv sync
uv run maxcode --help
