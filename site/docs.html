Docs

Configure

Create maxcode.toml in your project with a provider, one model for the planner, one model for the worker, and limits.

Commands

  • maxcode run TASK - plan, edit, and verify.
  • maxcode plan TASK - show the plan and stop.
  • maxcode undo - restore the last checkpoint.
  • maxcode cost [RUN_ID] - show the cost of a run.
  • maxcode bench - run the benchmark suite.

Checks

maxcode detects test, build, and lint commands for Python, Node, Rust, and Go repositories.
