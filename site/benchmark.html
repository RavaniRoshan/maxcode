benchmark

No score without a log.

A pass rate is only useful if you can inspect the run that produced it. This page publishes a number only next to the raw log, the task suite, and the model settings.

Method principles

Pinned repositories

Each task names a public repository and an exact commit. The runner clones the commit, not a moving branch.

Pass rate and tokens

A task passes only when its separate score command exits zero. Tokens and cost are summed per completed task.

Raw logs

Check output, token usage, cost, and final state are written next to the task. The score command is not passed to the worker.

method

Same tasks. Two configurations.

Both arms clone the same pinned commit, run maxcode with the verifier on or off, and then run the task's score command outside the loop. The score command is identical in both arms.

The default suite has 20 task files. The published run below is a 3-task subset, not a claim about the full suite.

results

3/3 in both arms. 0-point gain.

The 2026-10-31 run used one task each from click, itsdangerous, and markupsafe. Planner: qwen2.5-coder:1.5b. Worker: qwen3:1.7b. Both through Ollama 0.31.1.

The verifier-on arm hit the 300-second worker timeout before verification. The repositories were unchanged, so the final score still passed. This is a ceiling effect, not evidence of an advantage. The worker, qwen3:1.7b, failed 3/3 on a 2026-11-01 re-run, so the timeout was not the verifier's doing. A fresh full-suite run on 2026-11-01 is blocked on planner quality; the probes are committed under docs/bench/2026-11-01/planner-probes/. The full method, every failure, and the blocker are in docs/BENCH.md.

Excluded: psf/requests at its pinned commit already fails four tests on a clean checkout in this environment. Its score command cannot pass regardless of the model, so it is not counted as a pass or a fail.

Reproduce

maxcode bench --verifier on  --suite docs/bench/2026-10-31/suite3
maxcode bench --verifier off --suite docs/bench/2026-10-31/suite3
uv run python -m maxcode.bench.report .maxcode/bench

The runner and suite live in src/maxcode/bench. Add a task by dropping a JSON file into the suite directory.
